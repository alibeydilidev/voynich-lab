# voynich-lab

Voynich el yazmasını çözmeye çalışmaz. Onu üreten sürecin türünü, simüle edilmiş hipotezlerle karşılaştırarak sınıflandırır.

```bash
pip install -e ".[dev]"
python -m voynich_lab.cli all
```

Çıktı: `results/report.md`.

Mimari, ilkeler, ilk bulgular ve yol haritası için `CLAUDE.md` dosyasına bak.
